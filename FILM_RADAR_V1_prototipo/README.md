# FILM RADAR V1 — Prototipo

Este prototipo es una primera versión visual y funcional para validar el concepto.

## Incluye
- Dashboard
- Radar de clientes
- Radar de rodajes
- Radar de artistas/música
- Radar de ofertas
- Puntuación 0–100 con datos de demostración
- Fichas de oportunidades
- Generación de mensajes personalizada
- CRM básico con estados
- Perfil profesional
- Persistencia local en el navegador

## Cómo probarlo
Abre `index.html` en un navegador moderno.

## Importante
Los datos actuales son ficticios. Esta V1 no conecta todavía con Google Maps, redes sociales, portales de empleo, productoras, correo ni otras fuentes externas. La siguiente fase debe sustituir los datos de demostración por fuentes reales y diseñar el sistema de captación respetando APIs, términos de uso y normativa aplicable.
